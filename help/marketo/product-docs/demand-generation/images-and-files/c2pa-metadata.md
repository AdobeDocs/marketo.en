# C2PA metadata in Marketo Engage

New laws are emerging around generative AI transparency, and Adobe is working to meet applicable requirements across jurisdictions. C2PA metadata is the provenance tool Adobe uses to meet the requirements of these laws.

C2PA metadata is durable, invisible metadata that records how a piece of content was created or edited. When you generate or edit an image with generative AI tools in Marketo Engage, C2PA metadata is automatically attached to that image (no action is required on your part). It is encrypted, tamper-evident information that can help viewers understand the lineage of content and ensure the integrity of brand assets. This information includes:

* **Issuer or Signer**: Information about the entity or company that issued the digital signature to certify or sign the asset.
* **Issue Date**: The date on which the C2PA metadata was applied to the asset.
* **Credit and Usage**: Information about the producer of the asset, including name, social media handles, or other identity-related information.
* **Process**: Records of any edits or modifications made to the asset.
* **Device Details**: Information about the app or device used to create or edit the asset.
* **AI Tool Used**: If generative AI was used to create the asset, the name of the model used may be included.
* **Other Pertinent Information**: Additional data is also included to help offer more context about the history of an asset.

## Actions that attach C2PA metadata

The following table summarizes when C2PA metadata is attached, based on the image action performed in image generation in Marketo Engage.

| Action | Description | C2PA metadata attached? | Use case example |
|---|---|---|---|
| **Use 'Generate image' tool** | Create a new image from a text prompt, from a reference image, or generate a similar image. | Always. The image is generated by generative AI, so it always carries fresh C2PA metadata. | A banner image for an email campaign is generated from a text prompt describing the desired visual. |
| **Crop an image** | Adjust an image to requested dimensions. | Only if the source image already had C2PA metadata. Cropping recreates the image's pixels, which would normally erase that C2PA metadata, so Marketo Engage reads it from the source image before cropping, then rebuilds and re-attaches it to the cropped result. Cropping itself does not add a new generative AI action; it preserves the existing one. | A generated banner image is cropped to fit a web page: the C2PA metadata is preserved through the crop. An uploaded stock photo used as a push notification background is cropped to fit the screen: since the stock photo carries no generative AI action, no C2PA metadata is created. |
| **Add a text overlay** | Render generated text on top of a background image. | Only if the background image already had C2PA metadata. Rendering the overlay produces a new image from the background plus the text, which would normally erase that C2PA metadata, so Marketo Engage reads it from the background image beforehand, then rebuilds and re-attaches it to the result. The overlay step does not add a new generative AI action. | A promotional headline is rendered as a text overlay on a generated background image for a landing page: the C2PA metadata from the background image is preserved. |

## Content types and their scope

**Images**: Covered. C2PA metadata is attached when images are generated with generative AI, and preserved through cropping and text overlay operations performed by image generation in Marketo Engage.

**Text**: Not applicable. Text-only outputs of image generation in Marketo Engage, such as copy generation, translation, and brand alignment suggestions, do not require C2PA metadata.

## What happens as your content moves

Marketo Engage preserves C2PA metadata associated with supported image assets. If an image contains C2PA metadata when imported into Marketo Engage, the metadata is retained when the asset is used in generated campaign content and outbound email experiences.
